cmd+shift+R

Se o aplicativo não funcionar conforme esperado, continue trabalhando com a CLI do Gemini para receber a funcionalidade esperada. Exemplo:

shell Hide the task form when the user is logged out. Update the security rules so the user can see their TODOs.

Continue testando o laboratório para adicionar os recursos que você quer ver no seu novo aplicativo do Firebase.
